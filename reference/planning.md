# Planning — 策划层纪律（契约 / 阅读模式 / 节奏 / 关系声明 / Fact ID）

> 本层是内容规划的**上游加固**，活在 SKILL.md 第 1 步（定内容）与第 2 步（建骨架）之间。
> 方法移植自 ppt-master plan-core（见 THIRD_PARTY_NOTICES.md），已改写为 blue-ib 口径；
> 渲染层权威不变（SKILL.md 十条铁律 + design-tokens.md）。讲话场景命中覆盖条款时仍以
> `speech-deck-writing.md` 为准。

## 1. 策划契约六要素（PLAN.md 头部固定块）

开工先写、写错全返工。PLAN.md 头部必须有如下六行（缺行 = `plan_contract` warn）：

```
tone: 路演 | IC                # 第 0 步已问；笔法与密度档
mode: 讲稿 | 平衡 | 演示        # 阅读模式，见 §2；缺省 = 平衡
audience: 一句话（谁看：投委会/客户/监管/内部经营会…）
purpose: 一句话（看完要理解/相信/记住什么）
action: 一句话（看完要做什么：过会/注资/认购/整改…）
core: 核心分歧或主题句一条（IC=the single disagreement；讲话=年度主题）
```

- **六要素是后续所有页的上游**：页纲连读检验（SKILL.md 第 2 步）读不通时，先回查契约再改页纲。
- `core` 全 deck 只有一条；任何一页的 key message 不能指向它以外的分歧。

## 2. 阅读模式三档（mode）

mode 与 tone 正交：tone 管笔法，mode 管**字密度与读法**。

| mode | 读法 | 字密度口径 | 适用 |
|---|---|---|---|
| 讲稿 | 观众逐字读（材料会下发细读） | 正文 16/dense 14 不变；单块正文可到 ~250 字；表格可到 8 行 | 投决会备案材料、信披版讲话 deck |
| 平衡 | 讲者带读 + 材料自明 | 默认档：单块正文 ~165 字上限、表格 ≤5–6 行（现行口径） | 大多数 IC/路演 |
| 演示 | 只听不讲（大字大图，材料是 backdrop） | 要点短句化、每页构件 1–2 个、少而大原则顶格执行 | 大会演讲、发布场合 |

mode 只调密度与句式，**不动字阶白名单与配色**；选定后写进 PLAN.md（`mode:` 行），全 deck 一档，不逐页切换。

## 3. 页面节奏（page_rhythm：anchor / dense / breathing）

页纲表加「节奏」列，每页三选一：

| 节奏 | 职责 | 元素数参考（content 页） | 典型页 |
|---|---|---|---|
| anchor | 全 deck 的锚点页：信息最密、论证最重 | ≥70（IC 档中位上沿） | 核心分歧页、估值页、风险登记册 |
| dense | 常规内容页 | 45–75 | 大多数论证页 |
| breathing | 呼吸页：少而大、视觉停顿 | <45 | 隔页后第一页、结论页、大图页 |

纪律：
- **节奏必须有起伏**：全 deck 不允许清一色 dense——anchor 页前后宜有 breathing/dense 过渡；连续 ≥4 页 dense 无 anchor 是编排事故（`page_rhythm_flat` warn）。
- 节奏列是**声明**，qa.mjs 用元素数实测比对（`page_rhythm_mismatch` warn）：声明 breathing 却写出 80 元素 = 声明或实现有一个错了。
- 结构页（封面/目录/隔页/收尾/CONF）不打节奏标，不受此闸。

## 4. 关系声明（每页内容卡第一行）

每张内容卡首行写本页的**信息关系**，它是图解选型的唯一入口（接 `reference/diagrams.md` 三级路由）：

```
关系: 递进 | 循环 | 层级 | 对比 | 汇聚 | 辐射 | 收敛 | 分解 | 时序 | 份额 | 桥 | 画像 | 罗列
```

- 一页一个主关系；写不出关系词的页 = 内容还没想清楚，退回内容卡。
- 关系词直接喂 SKILL.md 第 3 步语义路由：递进→chevron 族、循环→环形族、层级→金字塔族……完整映射见 `diagrams.md` §1。

## 5. Fact ID 溯源（数据纪律）

- PLAN.md 末尾挂 **fact 台账**：`F1: 2025 营收 83.2 亿（年报 p12，截至 2026-04 披露）`——每条数据一个 Fact ID，含出处与期次。
- 内容卡与页面正文引用数据时带 `[F#]` 角标意识（正文可不显式写出，但写页时每个数必须能回指台账条目）；**台账之外的数不上页**。
- 打星纪律（信披场景）优先于本层：该打 `*` 的项永远打星，台账里记口径不记数值。

## 6. 封面 / 收尾 impact 强制

- **封面必须三件套**：主标题（主题/slogan）+ 会议或材料全称 + 日期/机构；讲话场景按 speech-deck-writing.md 的对仗 slogan 规格。
- **收尾页必备**：末页 = pageType final（讲话场景 = L05），带本 deck 自己的收口句；不得以内容页戛然结尾。缺失 = `closing_missing` warn。
- 目录页条目 = 观点句（铁律 2 同级），已有 `toc_msg_viewpoint` 闸兜底，本层不重复。

## 7. 与既有流程的接口

- 本层产物全部落在 PLAN.md：契约六行（头部）→ 页纲表（含节奏列）→ fact 台账（尾部）。
- 页纲冻结规则不变（SKILL.md 第 2 步：title 连读检验不过不许进第 3 步）。
- qa.mjs 对本层的机械闸：`plan_contract`（六要素缺行）/ `page_rhythm_mismatch` / `page_rhythm_flat` / `closing_missing`，全部 warn 级——策划判断由人裁决，闸只负责提醒失配。
