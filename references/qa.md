# 验收边界

1. 生成前确认用途、来源、事实与口径；按关系选择图解，不虚构模块填满网格。
2. 检查输出PPTX的可编辑文字、形状、表格与原生图表；完整数值需与内嵌工作簿一致。检查器不是完整ECMA-376 schema验证器。
3. 在目标客户端导出实际PPTX，查看全部页和整套缩略图；逐页检验字体、断行、同级字号、密度、碰撞、连接、图表标签及数据表。只过XML或替代渲染器不能声称PowerPoint/WPS通过。
4. 压力测试含同主题短中长、混排长标题、60/240字不对称模块、1/2/4/7项、图表及8×7长表头。超过角色容量先换版或拆页，不删事实和数值。
5. 编辑契约与生成测量分开。代表文本增字约30%，在目标应用保存、关闭、重开并检查；记录具体内容、字号、几何与客户端。不能承诺任意编辑自动协调。

`npm test`检查生成与机械不变量，视觉状态仍pending。公开包与私有定制稿不同；不要把私有审美评分、公司参考稿或其他客户端验证结论搬作本包的验证结果。
