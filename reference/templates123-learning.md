# 蓝色模板风：布局、字体与 UI 规则

本文件记录从用户授权模板中抽象出的通用关系与网格。公开版只保留重新实现的自适应生成能力，不分发第三方原稿参考页、字体或真实公司标识。

## 自适应模式

- `scripts/template-relations.mjs` 实现 3 种关系，由实测字体控制等宽栏、共享表头、完整证据行和续页；不是逐像素复刻。
- 指定模板风时，整套使用 `palette: template-blue`：主蓝 `0A579B`、次蓝 `063F8E`、浅蓝 `DCEEFC`、橙色 `FF7829`。既有配色与 `cpic-source` 兼容标识继续保留，不在一套 deck 中随意换主题。
- 正文默认案头 18pt、投影 22pt，不照抄参考稿的密集小字。
- 中文楷体搭配 Arial 是可选风格。`fontProfile: template-kai` 选择本机可用的 KaiTi；KaiTi 不等同于其他楷体。字体文件必须已存在，不下载或打包字体，不承诺跨设备不替换。普通商务内容可用 `business-sans` 或显式 `font`。

## 已接入的 3 类关系

| 关系/网格 | 输入 | 保留与重排 |
|---|---|---|
| 左侧循环概览，右侧编号与证据共享行基线 | `relationship: cycle` + `steps`（3–6 项）、`centerLabel`；或 `cycleEvidence` | 原生圆环与方向标记；长证据转宽行，保留闭环顺序；超长单项按句界保序续页 |
| 有序箭头抬头 + 对齐阶段/行动/交付区 | `relationship: sequence` + `steps`；或 `phaseBand`，可选 `summary` | 最多 3 栏；只有顺序关系才画箭头；不对称内容转宽行，保留结论与全部阶段 |
| 共同目标屋顶、同级支柱、共享基础 | `roof` + `pillars`（2–4 个 `title/body`）+ `foundation`；或 `strategyHouse` | 不虚构支柱；同级字号一致；长文先概览再续页，共同基础完整保留 |

真实日期跨度使用 `timeline`，不能把等距装饰称为真实工期。图标只选同笔画、同隐喻的语义图标；深色版仅在有明确需求时使用，默认白底。

## 版式纪律

1. 标题、栏目、证据、补充说明分角色；蓝色实心抬头用白字，浅蓝承载分区，橙色承担动作或计划语义。
2. 共享尺寸体现同级，不让同级模块各自缩小；事实数量由内容决定，不为了对称虚构模块。
3. 留白来自边距、模块间距与对齐，不用重阴影、透视或纹理掩盖内容关系。
4. 屋顶只表达共同目标，柱高不表示数值；循环必须真实闭环，阶段箭头只表达已确认顺序。
5. 生成期预留与后续 Office autofit 分开；不承诺任意文本框、任意增字仍自动协调。
6. 超长单项续页记录 `contentSegments`；检查器核对原文分片拼接相等及各片真实可见，不因拆页静默删事实。

验收以当前版本的实际回归为准。结构检查通过不等于视觉通过；未在目标客户端验证时不得宣称兼容。
