# 讲话类 deck 写作与格式规范（领导讲话 → PPT）

> 本文件只保留从用户授权材料中抽象出的通用写作与格式规则。公开版不分发原稿、个人姓名、机构文号、真实经营数据或本机证据路径。
>
> 与主体系关系：本文件是「讲话场景」的覆盖层；命中覆盖条款时以本文件为准（§6），未覆盖处回主体系铁律与配方。

## 1. deck 骨架（固定页型序列）

```
照片封面 → 保密提示（需要时置于 p2）→ [隔页 → 内容簇] × N → 照片收尾页
```

- 默认不强制目录页或感谢页；章节隔页可承担导航。
- 内容簇可含编号续页与同版式平行页；是否使用保密提示由用户材料和使用场景决定。
- 年中或阶段汇报可用两张照片隔页区分上下半场。

## 2. 签名格式手法

### 2.1 仪式三页：照片封面 / 照片隔页 / 照片收尾

- **共用构造**：全幅照片 + 深色蒙版 + 大字文案。照片可使用城市、山、海、船等隐喻，统一蓝调；素材须由用户提供或具有使用权。
- **隔页暗化**：整页深蓝蒙版，右侧保留部分原图亮度；不必裁成两张图。
- **收尾暗化**：深蓝渐变蒙版，标题与正文保持足够对比度。
- **封面文案**：对仗 slogan 双行 + 可选短标签 + 会议全称与日期。
- **隔页文案**：两行，第一行白、第二行使用深底强调色。
- **收尾文案**：左侧两行对仗，大字口号配破折号注解；本体系就近使用 44/28pt 专用字档。

### 2.2 章节导航隔页

- 同一底版可重复 N 帧，帧间只改变导航高亮；底版、标题和编号逐帧一致。
- 当前章节居中放大并加亮，其余章节缩小或半透明；没有动画时用静态「PART N」标签。
- 副标题可用对仗句，例如「回顾阶段成果，明确下步方向」。
- 章内可设置一句 slogan 的副隔页，但不得加入原材料没有的数字或事实。
- 章节导航与独立目录页按叙事需要二选一，避免重复。

### 2.3 编号续页

- 标题写作「主题名（k/N）」，k=1..N；同主题各页保持相同版式，只替换内容。
- 平行页可分别承载不同业务模块，但不得为凑数量虚构模块。

### 2.4 保密提示页

- 白底、灰色标题与深蓝正文；是否固定于第 2 页由用户要求决定。
- 公开通用模板如下，使用前须由用户按所在机构现行制度审核或替换：
> 根据《信息披露管理办法》《保密管理实施细则》以及内幕信息管理相关规定，本次会议可能涉及尚未正式披露的信息，请与会人员严格保密。如因信息提前泄露而影响正常披露或工作秩序，将按相关规定核查处理。特此提示。
- 技能不内置任何机构的文件编号、固定年份或正式制度文本。

### 2.5 内容页基因件

- **双色标题**：浅色底用蓝 + 橙，深色底用白 + 金；标题左下可配短粗线。
- **章节号与策略标签**：用于定位，不承载未经证实的新事实。
- **分带**：2–3 条横向带，带底浅蓝圆角板，带名用深蓝标签。
- **顶部或底部 slogan**：保持简短；与 KPI 带冲突时优先保留数据证据。
- **KPI callout**：超大数字配简短判断；未公开或不可披露的数据使用用户确认的占位符。
- **警示与清单**：警示色仅用于真实风险，清单项使用统一图标和层级。
- **氛围打底**：可选低饱和城市剪影，不抢正文；素材不随公开包分发。

## 3. 语言规范（讲话文体）

### 3.1 数字概括系统

- 可采用「数词 + 名」的概括框架，先命名后逐项解释，逐项句式对齐。
- 每个框架至少有一个标题级页面；内容过多时用「总页 + k/N 分页」或结构图。
- 框架名称必须来自用户材料或明确获得用户确认，不自行编造口号。

### 3.2 对仗与口号

- 优先使用两句长度接近的对仗句，保留原文引号术语。
- 可使用三项排比增强节奏，但每项必须有相同语法角色。
- 允许把平实原文提炼为对仗句；提炼不得增加原文没有的数字、事实或承诺。

### 3.3 比喻与结构

- 军事、建筑、航海等比喻只作语言组织，不改变事实含义。
- 宏观结构可用「回顾 → 研判 → 部署」，内容页内部可递归「成绩—问题—举措」。
- 检视不足位于成绩之后、部署之前；问题与后续行动须能对应。

### 3.4 数据话术

- 数字与判断捆绑呈现；对标对象优先匿名，真名须有来源和使用依据。
- 外部案例及数字必须来自用户材料或可核验来源，不能用示例数字补空白。
- 不为了积极叙事把下降改写成增长；趋势判断须与原始口径一致。

## 4. 转化法则（讲话 → deck）

### 4.1 压缩率

- 可将 deck 总字数约为讲话原文的 50%–60% 作为编辑起点，而非硬指标。
- 内容页原则上不超过 400 字，隔页不超过 20 字；超限时优先拆页或重排。

### 4.2 取舍

- **优先上页**：原文框架、目标数字、核心口号、责任清单、有来源的对标数据和引语。
- **优先压缩**：客套、重复过程铺陈和不影响判断的背景细节。
- **不得擅自增补**：具体机构名单、责任人、经营数字或时间节点；原文含糊时保留含糊或向用户确认。

### 4.3 标题句式

- 讲话类标题可用「短主题词 + 四字判断词」双段短语，数字放图区或表区。
- 判断词示例：稳固向好、步伐加快、持续深化、精准施策、提质增效。
- 章节页也可用动宾短语加对仗副标；banner 与结论句仍遵循主体系的完整判断要求。

### 4.4 要点句式与强调分工

- bullet 使用无主语动宾短语或「一是/二是/三是」，单条尽量不超过两行。
- 引号术语逐字保留；解释放次级正文。
- 橙色用于数字和判断，蓝色用于框架和术语，金黄用于深底标题强调；避免整页过度着色。

### 4.5 口号落位

- 封面使用本次材料主题口号；隔页使用极简章节名；收尾页优先使用该讲话自己的收尾口号。
- 外部案例可放附录并匿名化，但数字与结论仍需来源。

## 5. 信息披露纪律

- 未公开、敏感或用户要求隐藏的数据使用 `*` 等明确占位，不得编造具体值。
- 可披露范围、指标口径和匿名规则以用户材料及适用制度为准，技能不作自动合规保证。
- 数据页保留必要口径注；占位数据可用空轴框，但不能伪装成真实图表。

## 6. 覆盖主体系条款汇总（讲话场景生效）

| 主体系条款 | 讲话场景覆盖 |
|---|---|
| 标题含数字 + 判断完整句 | chrome-title 可用「主题词 + 四字判断词」；banner 层不变 |
| 独立目录页 | 可撤，由章节隔页承担导航 |
| 白底光弧封面 | 可选有使用权的照片封面变体 |
| 白底隔页 | 可选照片章节导航组 |
| 无收尾页型 | 可增照片收尾页，使用 44/28pt 专用字档 |
| 禁手绘数据图 | 仅允许明确标注的空轴占位框 |
| 数据必须填实 | 经用户确认的 `*` 占位合法 |

## 7. 讲话类 deck checklist（15 条；【qa】可机械闸/【文】写作自检）

1. 【qa】封面含主题口号、会议全称和日期。
2. 【qa】需要保密提示时，包含「信息披露管理办法/保密管理实施细则/内幕信息/严格保密/特此提示」五类提示语；正式文本由用户审核。
3. 【qa】每个「数词 + 名」框架至少一个标题级页面；分项拆页带 (k/N) 编号且与页序一致。
4. 【qa】页序为回顾/检视 → 检视不足 → 部署；检视不足与后续行动可对应。
5. 【qa-warn】内容页标题优先「短主题词 + 四字判断词」，避免无依据的夸张判断。
6. 【qa-warn】每个大部有隔页或框架导航；多段导航列全部段名并高亮当前段。
7. 【qa-warn】部署页 bullet 句式统一，单条尽量不超过两行。
8. 【qa】量化目标与讲话原文或用户确认数据一致。
9. 【qa】引号术语与原文逐字一致；自创术语须明确标识并经确认。
10. 【qa-warn】强调色分工一致，单页强调范围适度。
11. 【qa】对仗句两句齐全、长度接近，原文引号保留。
12. 【qa】末页使用深底和材料自身的收尾口号，与封面呼应。
13. 【qa】敏感或未公开数字不得意外出现；数据页保留必要口径注。
14. 【qa-warn】内容页密度和压缩比以可读性为准，超限重排或拆页。
15. 【文】可提炼对仗句，但不得加入原文没有的数字、事实、机构或责任承诺。
