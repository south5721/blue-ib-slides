# 蓝色图解系统与验收

4.4.1 将默认路由从 blue-editorial 改为 blue-ib。默认语言是短蓝色标题横线、蓝色胶囊标签、橙色动作词、细线框与原生关系图；颜色必须承载语义。公文条目仍可显式选择，不与图解默认混淆。

|内容关系|选版|超限处理|
|---|---|---|
|三项短模块|蓝色横带 + 三张轻渐变卡片；标签、动作、正文按共同基线|保持组内字号，改为证据行|
|二/四项并列|图标圆盘 + 胶囊标签 + 橙色动作 + 纵向分隔|改为证据行，避免长标签挤压|
|单项、多项、长文、带指标|蓝色标签 → 箭头 → 白色证据框|标签稳定高度，正文顶部对齐；按完整文字续页|
|共用中心|可编辑渐变球体、轨道与分支证据|过长中心标签明确失败；不缩成无法阅读小字|
|双图比较|宽窄图面板、统一蓝橙数据语义、细网格|需要完整原生 Chart/XLSX；过密标签明确处理|
|目录、比较、时间线、指标页|保留适合内容的专项布局|沿用对应容量及事实检查|

网格：13⅓×7.5 英寸，标题左侧约 0.54 英寸、顶部约 0.32 英寸；内容在完整标题和副标题后开始，页码在左下。3 卡片固定共同横向位置，纵向根据标题与动作实际高度计算。分隔线不能压住动作词。长证据行不把左标签拉伸为巨大色块。

字体：显式 font / BLUE_IB_FONT 优先；选择能实测的本地字体并记录，缺失的指定字体报错。已装优设标题黑可用于默认图解，不给其额外伪粗；其他中文字体是兼容选择，不能称字形完全复刻。案头正文默认 18pt、投影 22pt；reference 密集卡片为明确案头选择，不在投影启用。

复现与迁移分开：相同内容对齐布局、字阶、配色、元素形态与整体协调；换内容检查上述语言是否延续、内容是否完整、层级是否清楚。不要用像素差或随意百分比替代说明；字号与留白的主动改良须单列。公开包只提供通用原生形状，不附带参考稿、标识、背景纹理或受限字体。

检查整套节奏，再逐页看实际 PPTX。生成期测量与 Office 编辑后的 autofit 是两件事。当前预留不能承诺任意增字，有限编辑只报告实测文字框、增长量、字体及应用。
